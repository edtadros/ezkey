# ezkey.app — Brand context for SEO

## Product

- **Name:** ezkey.app
- **One-liner:** A macOS menu bar extra for generic passwords in the login Keychain.
- **Pricing:** Free MIT source. No hosted product. Build from github.com/edtadros/ezkey.
- **Free tier?** Yes — the whole app is free source.

## Audience

- **Primary persona:** Solo macOS developers who keep API tokens on one machine.
- **Jobs:** Save a key without `.env`; retrieve it without `security` flags; keep `security` CLI compatibility.

## Competitors

| Brand | Notes |
|---|---|
| Keychain Access | Same file, broader UI |
| security(1) | Same file, CLI |
| 1Password | Hosted vault, sharing |
| Bitwarden | Hosted vault |
| PassStore / NoxKey | Other local Mac vaults |

## Voice

Honest, technical, no warranty. Do not claim Secure Enclave for login.keychain-db. Do not trash 1Password.

## Anti-positioning

Not iCloud Keychain. Not a team vault. Not a browser password manager. No account, no server, no recovery desk.
