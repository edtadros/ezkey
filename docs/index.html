A menu bar for the Keychain you already have.

ezkey does not keep your secrets. macOS does. There is no account, no server, and no warranty.

Build from source Read the disclaimer

There is no official downloadable app until a GitHub Release is signed with Developer ID and notarized by Apple. If you did not compile it, do not grant it Keychain access.

Always Allow is a standing grant to this program’s code signature, including later copies you install. Use it only for a build you trust.

What it does

ezkey is a small macOS menu bar app. You save, update, and retrieve generic passwords in your login Keychain under a service name and account, the same items security add-generic-password and security find-generic-password use.

Secrets stay on your Mac. On Retrieve, type part of the service name to list matches, then pick one. The secret stays masked until you click Reveal. Copy clears the clipboard after 30 seconds if it still holds what ezkey put there.

What it does not do

  • It does not send data anywhere.
  • It does not create an account or back up your Keychain.
  • It does not bypass macOS permission dialogs.
  • It is not sandboxed, because a sandbox would hide items from the security CLI.
  • It is not supported software. If it breaks, you keep the pieces.

Build it yourself

Requires macOS 14 or later and Xcode command-line tools.

git clone https://github.com/edtadros/ezkey.git
cd ezkey
./scripts/build-and-run.sh

That produces a local build/ezkey.app. Ad-hoc signing is for that machine only. A public zip is produced only by scripts/release.sh, which refuses to run without Developer ID credentials and Apple notarization.
