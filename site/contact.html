Contact

The only email is hello@ezkey.app. There is no phone number, no ticket queue, and no promise of a reply. Use GitHub for anything that belongs in public, and use private advisories for anything that could expose secrets.

Security reports belong in a GitHub security advisory. Do not attach Keychain dumps, live API keys, or screenshots that show a secret. Follow the process in SECURITY.md.

Build questions, bugs that are not secret-bearing, and source changes belong on github.com/edtadros/ezkey. Open an issue or a pull request. The website is static files on Cloudflare; product policy is in the disclaimer and privacy pages.

There is no sales inbox and no enterprise support contract. If a page on this site is wrong, file a GitHub issue or write hello@ezkey.app. Do not invent other addresses.
