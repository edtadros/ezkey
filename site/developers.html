Developers

ezkey is a local macOS menu bar extra. The native app has no network API. This page describes the public website interfaces agents can use to read product docs. Secrets never leave the Mac.

When to use these interfaces

Use them to explain ezkey, fetch build steps, or retrieve a Markdown page. Do not use them to store or sync Keychain items.

REST API

Base URL: https://ezkey.app/api/v1. Current major version is 1, also sent as the API-Version response header. Breaking changes require a new major path. Deprecated routes will carry RFC 9745 Deprecation and Sunset headers with at least 90 days of notice. There is no scheduled deprecation today.

  • GET /health — liveness
  • GET /overview — product summary
  • GET /build — clone and build commands
  • GET /pages/{page} — Markdown for a named page
  • GET / — catalog of endpoints
  • GET /agent-brief — repo, disclaimer, clone, and run steps
  • GET /disclaimer — as-is terms an agent must present
  • GET /install — clone and build commands
  • GET /auth — no keys; public sandbox
  • GET /cli — no CLI; points to the install skill
  • GET /version — versioning and deprecation policy

Errors use RFC 9457 application/problem+json with a machine-readable code, a human-readable detail, and a resolution hint. Unknown /api/v1/* paths return HTTP 404 in that shape. Rate limit: 10 requests per 10 seconds per client IP, enforced by Cloudflare. Responses include RateLimit-Policy. HTTP 429 includes Retry-After.

OpenAPI: /openapi.json. Catalog: /.well-known/api-catalog.

MCP and A2A

MCP Streamable HTTP is https://ezkey.app/mcp (alias /api/v1/mcp). Tools: get_overview, get_build_instructions, get_agent_brief, get_disclaimer, get_page. Server card: MCP server card.

A2A JSON-RPC is POST /a2a. Agent card: /.well-known/agent-card.json. message/send answers from public site text. Tasks are not persisted.

Authentication

None. See auth.md. The site does not issue OAuth tokens. Protected-resource metadata: /.well-known/oauth-protected-resource.

Command-line

There is no ezkey CLI package. Agents install ezkey by following the build-ezkey skill: disclaimer, clone of the newest release tag, code review, then ./scripts/install.sh after the human says go. See CLI. No API key is issued. Production is the sandbox.

curl -sS https://ezkey.app/api/v1/agent-brief
curl -sS https://ezkey.app/api/v1/overview

The Keychain itself is reached with Apple’s security tool after you build ezkey locally, not through this website. Versioning: versioning policy.
