Guides

Short answers to the questions people actually type: how to save API keys securely on a Mac, whether .env is safe, and when 1Password is the better tool. ezkey.app is a local menu extra for the login Keychain. These pages are the public answers.

Questions

How can I save API keys securely on a Mac?Login Keychain, not .env.
What is the best way to store API keys on macOS?Local Keychain vs a team vault.
Is it safe to put API keys in .env files?Plaintext. gitignore is not encryption.
How do I store an OpenAI API key on a Mac?Do not append it to ~/.zshrc.
How do I use security add-generic-password?Prompt for -w. Match -a and -s.
Is there a Keychain GUI for developers?Menu extra, same file as the CLI.
Where should local API keys live?login.keychain-db if they must not leave.
Keychain vs 1Password for API keys?Local drawer vs shared vault.
ezkey vs Keychain Access?Same database, smaller job.
