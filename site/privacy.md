# Privacy

ezkey has no privacy policy in the usual sense because it has no one to send data to.

## The app

ezkey does not include analytics, crash reporters, advertising, accounts, or network calls. Secret values are stored only in your macOS login Keychain. The name you type may be remembered in local preferences on your Mac. Clipboard contents you copy are held by macOS; ezkey asks the pasteboard to clear after 30 seconds only if it still matches what ezkey copied.

The authors never receive your Keychain items.

## This website

These pages are static files on Cloudflare. They do not set cookies, load third-party scripts, or include analytics. Cloudflare may process ordinary request logs under Cloudflare’s terms. This project does not add to that.

## GitHub

If you open an issue, pull request, or discussion, that content is public on GitHub. Do not paste secrets there. Vulnerability reports belong in a private GitHub security advisory.

See the [glossary](https://ezkey.app/glossary.md).
